Windows 10 or 11, 64-bit. No installer and no .NET download — the runtime is bundled.

The easy way: the itch.io app

Install through the itch.io desktop app and it handles the download, the extraction and the updates, and you will not see the security warning described below. If you already have the app, this is one click and you can skip the rest of this section.

The other way: the zip

  1. Download the zip and extract it. Extract it properly — right-click, Extract All. Running straight out of the zip preview will fail, because the game needs the files next to it.
  2. Run RatnaBay.exe from the extracted folder.

Windows will warn you. This is expected.

You will see "Windows protected your PC" from SmartScreen. That warning means the executable is not code-signed, which is true — a signing certificate costs a few hundred a year and this is a free alpha.

To run it anyway: click More info, then Run anyway.

If you would rather not, that is a completely reasonable call and I would rather you skipped it than clicked through a security warning on my say-so. The itch.io app above avoids the prompt entirely.

Where it puts things

Saves, settings, and recordings live in %APPDATA%\RatnaBay. Paste that into the address bar of any Explorer window to open it.

Nothing is written to Program Files, nothing is added to the registry, and nothing runs at startup. To uninstall: delete the folder you extracted, and delete %APPDATA%\RatnaBay if you want the saves gone too.

If it will not start

  • It opens and closes instantly. Almost always an incomplete extract. Delete the folder and extract the zip again.
  • An error about a missing DLL. Same cause — a file did not make it out of the zip. Some antivirus tools quietly quarantine files mid-extract; check the quarantine log.
  • A black window, or it will not go fullscreen. Press F11 to toggle windowed mode.
  • Anything else. Tell me your Windows version and what you saw, at the address in the description above. If the game got as far as the menu, there will be a recording of the session in %APPDATA%\RatnaBay\recordings — attaching the newest one tells me far more than a description can.

Controls

The game explains itself as you go, so you should not need these. If you want them anyway: W A S D move, mouse look, left click attack, right click guard, E interact, I your pack, Q cast. Press F1 in game for the full list, and Tab to release the mouse.
