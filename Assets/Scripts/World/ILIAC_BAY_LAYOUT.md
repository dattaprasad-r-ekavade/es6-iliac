# Iliac Bay map layout (homage)

Reference geography from public lore (UESP / Daggerfall maps) — **not** a copy of Bethesda artwork.

## Orientation
- **+Z = North**, **+X = East**
- North: **High Rock** (temperate / green)
- South: **Hammerfell** (arid / sand)
- Center: **Iliac Bay** (ocean)
- West opens toward the Abecean Sea

## Landmarks placed
| Location | Role |
|---|---|
| Daggerfall | High Rock SW peninsula city (player spawn) |
| Wayrest | High Rock east shore / Bjoulsae side |
| Sentinel | Hammerfell NW coast city |
| Betony | Western bay island |
| Balfiera | Central bay island + tower homage |
| Cybiades | Island north of Sentinel coast |
| Wrothgarian foothills | Northern High Rock hills |
| Alik'r | Southern Hammerfell desert expanse |
| Dragontail foothills | SE Hammerfell rocky hills |

## Rebuild
Unity menu: **Elder Scrolls 6 → World → Build Iliac Bay Map (High Rock + Hammerfell)**
